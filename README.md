# 🎸 Conciertos Masivos — Latinoamérica & USA (1985–2024)

Dashboard interactivo con datos históricos de conciertos masivos en Argentina, Brasil, Colombia, México, Perú y Estados Unidos.

## 📊 Visualizaciones

- **Evolución anual** por país (líneas)
- **Distribución apilada** por año y país (barras)
- **Ranking acumulado** por país
- **Mapa de calor** de intensidad histórica
- **Tabla de datos** completa con filtros

## 🚀 Deploy en Streamlit Cloud

1. Hacé fork de este repositorio en tu cuenta de GitHub
2. Entrá a [share.streamlit.io](https://share.streamlit.io)
3. Conectá tu cuenta de GitHub
4. Seleccioná este repo → rama `main` → archivo `app.py`
5. Hacé click en **Deploy** ✅
